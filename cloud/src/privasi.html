Kebijakan Privasi aina

Berlaku untuk aina Cloud (akun berlangganan) · Versi draf, 19 Oktober 2026

Draf ini disusun mengikuti UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi dan wajib ditinjau konsultan hukum sebelum aina Cloud dibuka untuk umum.

1. Siapa kami

aina ("aina") adalah aplikasi pendamping di Windows yang melihat layar saat kamu bertanya, menunjuk, memandu, dan bisa mengerjakan tugas atas izinmu. Pengendali data untuk aina Cloud adalah pengembang aina (kontak: privasi@badi.id).

2. Data yang kami proses

Di PC-mu, aina hanya menyimpan pengaturan dan apa yang kamu minta simpan (lihat dokumentasi aplikasi). Rekaman suara dan tangkapan layar hanya ada di memori.

3. Dasar pemrosesan

Kami memproses data atas dasar persetujuanmu saat mendaftar dan untuk melaksanakan perjanjian langganan. Kamu bisa menarik persetujuan kapan saja dengan menghapus akun.

Sebagian penyedia memproses data di luar Indonesia. Kami memilih penyedia yang tidak memakai data API pelanggan untuk melatih model, sesuai ketentuan mereka masing-masing.

5. Hak kamu

  • Melihat data akunmu di Settings → Akun.
  • Menghapus akun dan data yang terkait dari Settings → Akun (tombol "Hapus akun"), atau lewat email ke kami. Data pembayaran disimpan terpisah tanpa akun selama diwajibkan aturan pajak.
  • Memutus aplikasi kerja kapan saja di Settings → Aplikasi kerja.
  • Mengajukan keberatan atau pertanyaan ke privasi@badi.id. Kami menjawab paling lambat 3×24 jam pada hari kerja.

6. Keamanan

Koneksi memakai HTTPS. Kode masuk sekali pakai dan token perangkat hanya disimpan dalam bentuk hash. Key penyedia AI hanya ada di server, tidak pernah di aplikasimu. Jika terjadi kegagalan pelindungan data, kami memberi tahu pengguna yang terdampak dan lembaga yang berwenang paling lambat 3×24 jam sejak diketahui.

7. Perubahan

Perubahan kebijakan diumumkan di aplikasi dan di halaman ini sebelum berlaku.

Lihat juga Ketentuan Layanan.
