## BE-17 · Paksa update app lama (saklar)

### Cara kerja
- Variabel baru `RETIRED_HOST_MESSAGE` di `wrangler.toml`, **kosong = mati** (default).
- Kalau diisi, semua panggilan yang **butuh akun** (API app: `/v1/account`, proxy AI, Composio, dst.) yang
  datang ke host di `ALT_PUBLIC_URLS` (workers.dev) dijawab:
  ```json
  HTTP 426 {"type":"error","error":{"type":"upgrade_required","message":"<isi RETIRED_HOST_MESSAGE>"}}
  ```
- App lama menampilkan `error.message` dari backend (`badi-app/src/cloud.rs:195`), jadi user melihat
  pesan update itu.
- **Tetap terbuka** di alamat lama, karena dicek sebelum saklar: `/`, `/ketentuan`, `/privasi`,
  `/download`, `/v1/plans`, login (`/login`, `/auth/*`, `/v1/auth/exchange`), webhook
  `/v1/billing/midtrans`, redirect Composio, `/admin/*`.
- `be.aina.ai.id` dan `aina.ai.id/api` tidak pernah terpengaruh.

### Kode
- `crates/badi-cloud-core/src/lib.rs`: `host_listed(host, list)` dan test
  `calls_on_an_old_address_are_told_apart` (case-insensitive, host saat ini tidak cocok, list kosong
  tidak cocok).
- `cloud/src/lib.rs` (`fetch`): pengecekan dipasang tepat sebelum "Everything else needs an account".
- `cloud/wrangler.toml`: `RETIRED_HOST_MESSAGE = ""` beserta contoh pesan.

### Verifikasi
```
cargo test -p badi-cloud-core     -> 34 passed; 0 failed
cargo check --target wasm32       -> OK
```

### Menyalakan (nanti, setelah 1.0.1 tersebar)
Isi di `wrangler.toml`, misalnya:
```toml
RETIRED_HOST_MESSAGE = "Versi aina ini sudah tidak didukung. Unduh versi terbaru di https://aina.ai.id/api/download"
```
lalu `wrangler deploy`. Verifikasi:
```
curl -s https://badi-cloud.faisalmashuri16.workers.dev/v1/account   -> 426 + pesan
curl -s https://be.aina.ai.id/v1/account                             -> 401 (normal, tanpa token)
```
Mematikan: kosongkan lagi, lalu deploy.

### Catatan desain
Pembeda app lama dan baru adalah **host**, bukan versi, karena app saat ini tidak mengirim versinya. Untuk
paksa update di masa depan (setelah workers.dev mati), sebaiknya app mengirim header versi (misalnya
`User-Agent: aina/1.0.1`) supaya backend bisa menerapkan versi minimum. Ini belum masuk ke 1.0.1.
