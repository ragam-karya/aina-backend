## Perubahan

```rust
let base = Some(secret(env, "COMPOSIO_REDIRECT_BASE")).filter(|b| !b.is_empty()).unwrap_or_else(|| secret(env, "PUBLIC_URL"));
format!("{}{}", base.trim_end_matches('/'), rules::REDIRECT_PROXY_PATH)
```

### `cloud/wrangler.toml`
```toml
PUBLIC_URL = "https://be.aina.ai.id"
ALT_PUBLIC_URLS = "https://badi-cloud.faisalmashuri16.workers.dev"
COMPOSIO_REDIRECT_BASE = "https://be.aina.ai.id"
```

**Penyimpangan dari plan:** plan awal mengisi `COMPOSIO_REDIRECT_BASE` dengan URL workers.dev. Hasil BE-02
menunjukkan **tidak ada** auth config yang memakai `viaBadi`, jadi nilai ini belum dipakai siapa pun.
Diisi domain baru supaya pendaftaran `viaBadi` berikutnya tidak bergantung pada workers.dev yang akan
dimatikan. Syaratnya, `https://be.aina.ai.id/api/composio-redirect` harus didaftarkan di console OAuth
provider sebelum `viaBadi: true` dipakai.

### Siapa yang terpengaruh `PUBLIC_URL`
Hanya dua pemakai di kode:
1. Origin check request bercookie, lewat `own_sites()`. Domain baru, workers.dev, dan `aina.ai.id`
   tetap diterima.
2. `proxy_uri()`. Sekarang dikunci oleh `COMPOSIO_REDIRECT_BASE`.

Google Sign-In (`FRONTEND_URL`), Midtrans (signature dan `FRONTEND_URL`), dan app desktop (URL
hardcoded) tidak terpengaruh.

## BE-10 · Smoke test otomatis (setelah deploy)

Tiga host: `be.aina.ai.id`, `badi-cloud.faisalmashuri16.workers.dev`, `aina.ai.id/api` (proxy website).
**Hasilnya identik di ketiganya**, dan tidak ada header `cf-mitigated`.

| Request | Hasil | Arti |
|---|---|---|
| GET /v1/plans | 200 (body identik di be & workers.dev) | API publik OK |
| GET /ketentuan, /privasi | 200 | halaman legal OK |
| GET /download | 200 | installer dari R2 OK |
| GET /v1/account tanpa token | 401 | auth jalan |
| POST /v1/auth/exchange `{}` | 401 JSON | Worker menjawab |
| POST /v1/billing/midtrans tanpa signature | 403 | verifikasi signature jalan |
| GET /login?app_state=x | 400 | `app_state` tidak valid (minimal 32 karakter), sesuai harapan |
| GET /login?next=/langganan | 302 → accounts.google.com | login web mulai |

**Redirect URI Google dari kedua host:** `https://aina.ai.id/api/auth/google/callback`, sama seperti
sebelumnya. Google Console tidak perlu diubah.

**Origin check** (POST /v1/checkout dengan cookie sesi palsu): Origin `be.aina.ai.id`, workers.dev,
`aina.ai.id`, dan `evil.example` semuanya 401, tidak ada 5xx. Dengan token palsu, hasil diterima dan
ditolak memang tidak bisa dibedakan dari luar. Pembuktian dengan sesi asli ada di checklist manual
no. 5.

Efek samping: dua panggilan `/login?next=…` per host membuat baris `oauth_state` di D1 yang akan
kedaluwarsa sendiri (`OAUTH_STATE_TTL_MS`). Tidak ada data lain yang tertulis.
